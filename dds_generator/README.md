# DDS Signal Generator for M5Stack Cardputer

**Version:** 1.0.0
**Platform:** M5Stack Cardputer v1.1 (ESP32-S3)
**Author:** Andy + AI

## Overview

True analog waveform generator using the **M5Stack DDS Unit (AD9833)** connected via Grove I2C.
Unlike the PWM-based signal generators in this repo, DDS produces clean analog waveforms directly from a DAC -- no RC filter needed.

## Why DDS is Better Than PWM

| | PWM Generator (signal_generator) | DDS Generator (this project) |
|---|---|---|
| Method | PWM + RC filter | Direct Digital Synthesis (DAC) |
| Signal quality | Approximate, has ripple | Clean analog output |
| Frequency precision | Limited | 28-bit (0.037 Hz resolution!) |
| Max frequency (sine) | ~2 kHz | 1 MHz |
| External filter | Required (1k + 100nF) | Not needed |
| Hardware | Just Cardputer | Cardputer + DDS Unit |

## Features

- **5 waveforms:** Sine, Triangle, Square, Sawtooth, DC
- **Frequency range:** 0 Hz to 1 MHz (sine/triangle), up to 12.5 MHz (square)
- **28-bit frequency resolution** -- sub-Hz precision
- **Frequency presets** + fine tuning (+/-10%, +/-1%)
- **Phase control** -- 0-360 degrees in 15-degree steps
- **Sweep mode** -- automatic frequency sweep
- **Output:** SMA connector, 0-0.6V amplitude (analog), 0-3.3V (square)
- **Real-time display** -- waveform type, frequency, phase, output state

## Hardware Required

- M5Stack Cardputer v1.1 (ESP32-S3)
- **[M5Stack DDS Unit (AD9833)](https://shop.m5stack.com/products/dds-unit-ad9833)** -- connects via Grove cable

### Connection

```
Cardputer Grove Port A (G2=SDA, G1=SCL) --[Grove cable]--> DDS Unit
DDS Unit SMA output --[wire]--> Oscilloscope input (G1)
```

No soldering, no external components -- just plug in the Grove cable.

## Building

Requires [PlatformIO](https://platformio.org/).

```bash
cd dds_generator
pio run                  # compile
pio run -t upload        # flash
pio device monitor       # serial output (115200 baud)
```

### Pre-compiled Firmware

```bash
esptool.py --chip esp32s3 --port /dev/cu.usbmodemXXXXX --baud 460800 \
  write_flash 0x10000 ../firmware/dds_generator_v1.1.bin
```

## Technical Notes

- AD9833 communicates via SPI (not I2C) internally, but the M5Stack DDS Unit wraps it with an I2C-to-SPI bridge (STM32 inside the unit handles the translation)
- Master clock: 10 MHz (M5Stack DDS Unit specific)
- Frequency register formula: `freq_word = (frequency * 2^28) / 10000000`
- Sawtooth wave is generated by rapidly sweeping frequency using a FreeRTOS task -- hardware-limited to ~13.6 kHz
- The `disableCore0WDT()` call prevents watchdog resets during the sawtooth generation task

## AD9833 Limitations

- Sine/Triangle output voltage: 0 - 0.6V (may need amplification for some applications)
- Square wave output: 0 - 3.3V (digital output, separate pin on some modules)
- Sawtooth is software-emulated, not native -- limited bandwidth
- At high frequencies (>100 kHz), expect DAC step artifacts (aliasing)
