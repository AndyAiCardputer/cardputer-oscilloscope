# Signal Generator for Cardputer ADV

**Version:** 2.1.0
**Platform:** M5Stack Cardputer ADV (ESP32-S3) -- internal 240x135 display
**Author:** Andy + AI

## Overview

Multi-waveform signal generator running on M5Stack Cardputer ADV using
the built-in 240x135 display. Same feature set as the
[Cardputer v1.1 signal generator](../signal_generator/), adapted for ADV hardware.

## Features

- **4 waveform types:** Square, Sine, Triangle, Sawtooth
- **Square wave:** hardware LEDC PWM, 1 Hz - 100 kHz
- **Sine/Triangle/Sawtooth:** software-generated via FreeRTOS task, max ~2 kHz
- **Adjustable frequency** with presets and fine tuning
- **Adjustable duty cycle** (square wave, 10% steps)
- **Waveform preview** on 240x135 internal display
- **Output:** GPIO 2 (Grove G2), 3.3V logic level

## Hardware

- M5Stack Cardputer ADV (ESP32-S3)
- Output wire from **G2** (GPIO 2) on Grove connector

### RC Filter for Analog Waveforms

For sine, triangle, and sawtooth waves, add an RC low-pass filter:

```
G2 (GPIO 2) ---[1k resistor]---+---> Output
                                |
                           [100nF cap]
                                |
                               GND
```

Square wave can be connected directly without the filter.

## Keyboard Controls

| Key | Function |
|-----|----------|
| W | Cycle waveform (Square/Sine/Triangle/Sawtooth) |
| + / - | Frequency up / down |
| D | Duty cycle adjust (square wave only) |
| G | Signal on / off |

## Building

Requires [PlatformIO](https://platformio.org/).

```bash
cd signal_generator_adv
pio run                  # compile
pio run -t upload        # flash
pio device monitor       # serial output (115200 baud)
```

### Pre-compiled Firmware

```bash
esptool.py --chip esp32s3 --port /dev/cu.usbmodemXXXXX --baud 460800 \
  write_flash 0x10000 ../firmware/signal_generator_adv.bin
```

## Difference from Cardputer v1.1 Version

- Does **NOT** delete I2C drivers (Cardputer ADV uses TCA8418 I2C keyboard on GPIO 8/9)
- ADV-specific initialization sequence

## Technical Notes

- Software waveforms (sine/triangle/sawtooth) are generated by rapidly modulating
  PWM duty cycle at 40 kHz carrier frequency using a FreeRTOS task on Core 0
- `disableCore0WDT()` prevents watchdog resets during tight waveform generation loop
- The RC filter smooths out the PWM carrier, leaving the desired waveform shape
